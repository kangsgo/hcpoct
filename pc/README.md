# POCT 皮质醇检测工作站（桌面版 · `pc/`）

基于 **Electron + serialport + SQLite** 的 POCT（即时检验）皮质醇检测上位机工具。
用于通过串口连接检测设备，实现 **测试数据（空白测试 / 样品测试）/ 串口设置 / 检测收发 / 历史记录** 全流程。

> 本目录是仓库中的**桌面端（PC）**工程，所有命令都在 `pc/` 下执行。
> 手机端（React + Web Serial）见 [`../mobile`](../mobile)，仓库总览见 [`../README.md`](../README.md)。

---

## 1. 功能一览

| 模块     | 能力                                                                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 测试数据 | 主界面只有两个按钮：**空白测试**（按设置中的采集参数定时采集空白并记录参照值）与**样品测试**（空白测试完成后可用，自动扣除空白参照值并保存样本记录）        |
| 串口连接 | 顶部「设置」二级菜单内：一键**扫描/发现**可用串口、**设置波特率**（含数据位、停止位、校验位）、连接/断开、收发字节统计                                     |
| 检测收发 | 「设置」内可**向串口发送任意数据**获取设备返回，自动分帧、自动解析数值、实时数据流日志（ASCII + HEX）、定时发送                                             |
| 结果换算 | 净信号 = 测量值 − 空白参照值；可选线性标准曲线换算浓度（ng/mL 等）                                                                                         |
| 历史记录 | **SQLite** 存储全部检测与校准数据，支持按类别/日期/关键词筛选、分页、删除、导出 CSV                                                                        |
| 设置     | 顶部「设置」二级菜单：串口连接、采集与发送参数、单位、校准参照窗口、标准曲线、默认波特率/超时/分帧、数据目录、清空数据                                      |
| 界面     | **亮色主题**（默认）、**中英文一键切换**（含菜单、弹窗、导出表头与 CSV 内容），语言记忆到数据库                                                            |

## 2. 快速开始

```bash
npm install          # 安装依赖
npm run rebuild      # 为 Electron 重建原生模块（better-sqlite3）
npm start            # 启动应用
npm run dev          # 启动并打开开发者工具

npm run smoke        # 自检：SQLite 数据层 + 串口扫描（Electron 环境）
npm run uicheck      # 自检：亮色主题 + 中英文切换（无头窗口）
```

> 若 `npm install` 后出现 `NODE_MODULE_VERSION` 不匹配的报错，执行一次 `npm run rebuild` 即可。

### 使用流程

1. 点击顶部 **设置** 打开二级菜单：**扫描** → 选择串口设备 → 填写 **波特率**（如 115200）→ 点击 **连接串口**；
2. 在「设置 → 采集与发送」中确认 **发送数据**（默认 `READ`，可切到 HEX 模式发送 `01 03 00 00 00 01`）、**定时间隔 / 定时次数** 等参数；
3. 回到主界面点击 **空白测试**，按采集参数自动采集空白并记录参照值；
4. 空白测试完成后 **样品测试** 按钮可用：放入样品后点击，自动读取数值、扣除空白参照值并保存样本记录（净信号与浓度同步换算）；
5. 在 **历史记录** 页筛选、导出 CSV。

## 4. 串口数据协议（自由协议）

本工具不绑定固定协议，**发送任意数据均可**，返回数据按以下规则处理：

- **分帧**
  - 「接收分帧 = 按空闲时间」：收到数据后空闲 `空闲分帧(ms)`（默认 120ms）即认为一帧结束，适用于无固定结束符的设备；
  - 也可选择 `\n`、`\r`、`\r\n` 作为分帧结束符。
- **数值解析**
  - 自动从返回文本中提取第一个数值（支持小数与科学计数法，会跳过 `CH1` 之类的通道号）；
  - 解析失败时原始数据仍会记录，可在「最近测量结果」中**手动填写数值**后保存。
- **HEX 模式**：发送内容按 `01 03 00 00` 形式填写（空格可有可无），发送前按 HEX 解码为字节。

## 5. 数据存储（SQLite）

数据库文件：`<userData>/poct-cortisol.db`（设置页可查看完整路径并打开数据目录），使用 WAL 模式实时落盘。

```sql
-- 检测/采集记录
measurements(id, category, value, unit, raw, payload, port, baud_rate, source, note, meta, created_at)

-- 空白校准记录
calibrations(id, kind, value, unit, raw, note, created_at)

-- 应用设置
settings(key, value, updated_at)
```

- `category` / `kind`：`blank`（空白）、`aptamer_blank`（适配体+染料空白）、`sample`（样本）
- `source`：`manual`（手动发送）、`timed`（定时发送）、`calibration`（校准采集）
- 保存 `blank` / `aptamer_blank` 类别时会同步写入 `calibrations` 表，用于计算空白参照值。

## 6. 测试数据说明

| 步骤     | 内容                                             | 作用                                                                        |
| -------- | ------------------------------------------------ | --------------------------------------------------------------------------- |
| 空白测试 | 按采集参数（定时间隔 / 定时次数）自动采集空白孔   | 记录空白参照值（参照值 = 最近 `校准参照窗口`（默认 5）次空白记录的**均值**） |
| 样品测试 | 单次发送并读取设备返回，自动扣除空白参照值后保存 | 样品测试在空白测试有数据前**保持禁用**，确保每个样本都有参照基准             |

- 采集参数在「设置 → 采集与发送」中配置，采集过程中可随时点击 **停止采集**；
- 结果面板同步显示 **净信号（扣除空白）** 与 **换算浓度**（需在设置中启用标准曲线）。

## 7. 界面语言与主题

### 亮色主题与品牌配色

界面默认使用**亮色主题 + 深绿医疗风**配色（白色面板、浅绿灰背景、深绿主按钮与点缀），顶部有一条深绿→青的渐变饰条。品牌标识使用根目录 `logo.svg` 派生的**深绿色版本** `src/assets/logo-green.svg`（将原白色填充 `#FFFFFF` 改为深绿 `#14532D`），出现在应用页眉与「设置 → 关于」面板。

所有颜色集中在 `src/styles.css` 末尾的「亮色主题」段落（CSS 变量 + 少量覆盖规则），便于后续扩展深色主题或其他配色。若更换 logo，只需重新执行：

```bash
sed 's/\.st0{fill:#FFFFFF;}/.st0{fill:#14532D;}/' logo.svg > src/assets/logo-green.svg
```

### 中英文切换

- 右上角 **EN / 中文** 按钮一键切换，当前语言会写入 SQLite `settings.lang`（并缓存到 `localStorage`，避免下次启动闪动）；
- 切换范围包含：静态界面文案、动态生成的表格/统计/提示，自定义确认弹窗、导出 CSV 的表头与类别名、应用菜单，以及导出/保存对话框的标题；
- 实现方式：`src/js/i18n.js` 以**中文原文作为翻译键**（gettext 风格），通过 `MutationObserver` 自动翻译新插入的文本节点与 `placeholder`/`title` 属性，并在切换语言时从缓存的原文无损还原。

新增界面文案时，只需在 `src/js/i18n.js` 中补充对应英文：

| 文案类型                                 | 添加位置                  |
| ---------------------------------------- | ------------------------- |
| 完整句子（如标题、按钮、表头）           | `EXACT` 对照表            |
| 带变量的句子（如 `已扫描到 {n} 个串口`） | `PATTERNS` 正则句式       |
| 会被拼进其他句子的短语（如类别名）       | `FRAGMENTS` 词组表        |
| 需要主动翻译的 JS 字符串                 | 调用 `POCT.t("中文原文")` |

需要原生确认框时请使用 `POCT.confirmDialog(message)`（返回 `Promise<boolean>`），它同样是可翻译的 DOM 弹窗。
